# OGE-ACTRA TECH website

Premium corporate technology website for OGE-ACTRA TECH — AI, Software Engineering & Digital Platforms.

## Run

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Configuration

- `NEXT_PUBLIC_SITE_URL` — canonical production URL.
- `NEXT_PUBLIC_CONTACT_ENDPOINT` — optional POST endpoint for contact submissions.

## Brand assets

The site uses the supplied OGE-ACTRA TECH logo and product visuals under `public/brand` and `public/products`.

## Product hierarchy

OGE-ACTRA TECH is the parent technology company. Its product ecosystem includes ACTRA AI, SchoolHub, WaShop, and P2BET.
